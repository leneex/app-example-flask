# Flask

Пример приложения [Flask](https://flask.palletsprojects.com/en/3.0.x/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/` |

Railpack видит Flask: ставит зависимости из `requirements.txt` и запускает `gunicorn main:app` на
порту из переменной окружения `PORT` — её передаёт платформа, — а без неё `8000`. Настройки
gunicorn — в `gunicorn.conf.py`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# виртуальное окружение и зависимости
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# запуск приложения
python3 main.py
```
