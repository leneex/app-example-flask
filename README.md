# Flask

Пример приложения [Flask](https://flask.palletsprojects.com/en/3.0.x/), которое можно развернуть без настройки.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
pip3 install -r requirements.txt --break-system-packages

# запуск приложения
python3 main.py
```
